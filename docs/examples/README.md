# Ejemplos de formato

Esta carpeta contiene **material de referencia**, no specs reales:

- `spec_typing_engine/` — ejemplo completo de los tres archivos de una spec, basado en F02 (`typing_engine`). Sirve como modelo de formato para el `spec_author`.
- `impl_report.template.md` — plantilla del informe del `implementer`.
- `review_report.template.md` — plantilla del informe del `reviewer`.

> Las decisiones de comportamiento del ejemplo (por ejemplo, que un error bloquee el avance) son **ilustrativas**. Las decisiones reales las toma el humano al responder las `open_questions` de la feature.
> Los specs reales se crean en `specs/<scope>/<name>/`; no copies estos archivos tal cual.
